How it works

使い方は3つだけ

1
Option+Space

書く

ショートカットキーで付箋が出現。どのアプリの上にも浮かぶ。思いついたことをそのまま書く。整理する必要はない。

2

整理する

Organizeボタンを1回押す。AIがタイトル、要点、チェックボックス付きアクションリストに変換。気に入らなければCmd+Zで元に戻せる。

3

実行する

チェックボックスをクリックして消化。終わったらCmd+Wで閉じる。メモはGroupに自動保存され、いつでも振り返れる。

Features

小さな付箋に、必要なもの全部

AI Organize

走り書きをタイトル、要点、アクションに構造化。短いメモはローカルAI (Ollama)、長いメモはClaude APIで処理。

学習型AI分類

メモを使うほど、あなたの分類パターンをAIが学習。自動でGroupに振り分けてくれる。

チェックボックス

Organize後のアクションリストはクリックでチェック可能。タスク管理アプリ不要。

Undo対応

Organizeの結果が気に入らなければCmd+Zで元の走り書きに戻せる。やり直し自由。

Inbox一括分類

溜まった未分類メモをまとめてAI分類。ボタン1つでInboxを空にできる。

カスタムショートカット

新規ノート、Groups表示、Archiveのキーバインドを自由に変更可能。

ターミナルって何? このコマンド貼って大丈夫?

ターミナル.app は Mac に最初から入っているアプリです。Spotlight (⌘ + Space) で「ターミナル」と検索 → Enter で開きます。インストールも追加設定も不要。

上のコマンドがやっているのは「公開リポジトリから zip を取って Applications に置き、起動する」だけ。隠れた処理はありません。コマンド全文を見れば全工程が読めます。

初回起動時に警告は出ますか?

出ません。v1.0 から Apple Developer ID で署名し、Apple の Notarization(公証)を取得済みです。ダブルクリックでそのまま起動できます。

AI Organize 機能 = 2 つの選択肢から 1 つ

手書きメモ / チェックリスト / グループ化だけなら AI なしでも動く。 AI で「タイトル + 要点 + アクション」 に整理したい時のみ どちらか 1 つを設定。

結局どっちがいいの?

迷ったら Ollama (Option A)。 完全無料、 外部送信ゼロ、 一度 setup したら永続。 メモが大量だと月額が読めない時の保険にもなる。

Mac が古い / RAM 少ない / 5 分の setup が面倒 なら Claude API (Option B)。 1 日 10-30 メモなら月額 ¥150-900 程度の目安。 setup 1 分で動く。

両方設定した場合 = Claude API が優先 (= 速いから)。 Ollama は API fail 時の fallback として残る。

どちらも設定しない場合 = AI Organize ボタンは表示されるが、 押すとエラーメッセージが出て 何も起きない (= 手書きメモ / グループ化 機能は問題なく動く)。

後から切り替えできる?

Flote 起動後 メニューバー Flote → Settings でいつでも切り替え可能。 設定変更後の再起動不要、 次の Organize ボタン押下から新 backend で動作。

メモのデータはどこに送られる?

Ollama 使用時: メモは Mac 内 (= localhost) で処理。 外部送信ゼロ。

Claude API 使用時: メモ 1 件分のテキストが Anthropic API に送信される。 Anthropic の プライバシーポリシー per、 API 経由のデータは 学習に使われません。 ただし「外部送信される」 事実は変わらないので、 機密情報を書く時は Ollama 推奨。

Flote 自体はメモを app 外に送信しません (= AI 整理 trigger 時のみ、 上記 backend に 1 件ずつ送る)。 ソース全公開なので OrganizeService.swift で実装確認可。

Windows 版を Flutter で開発中です

Mac と同じく PowerShell ワンライナー で警告ダイアログなしのインストールを予定しています (Invoke-WebRequest で取得すると Mark of the Web が付かないため SmartScreen 警告が出ません)。

下記は 完成時に動く予定のコマンド です。今はまだダウンロード先のファイルが存在しないため動きません。完成時にこのページが自動的に更新されます。

# 完成時のインストールコマンド (現時点ではまだ動きません)
Invoke-WebRequest -Uri "https://flote-app.vercel.app/Flote-windows.zip" -OutFile "$env:TEMP\Flote.zip"; Expand-Archive -Force "$env:TEMP\Flote.zip" -DestinationPath "$env:LOCALAPPDATA\Flote"; Start-Process "$env:LOCALAPPDATA\Flote\Flote.exe"
1. ダウンロード -> 2. LOCALAPPDATA に展開 -> 3. SmartScreen 警告を回避 -> 4. 起動
Windows 版で予定している機能
  • システムトレイ常駐 (Mac のメニューバー相当)
  • グローバルホットキー (Win + Space 等で付箋出現)
  • Mac 版と同じ AI Organize / Groups / 学習型分類
  • Mac との設定同期は将来検討
いつ完成しますか?

Flutter (Dart) で開発中です。Sprint 1 (基盤構築) が現在進行中で、Sprint 6 (配布パッケージ化) で公開予定。Mac 版の検証フェーズと並行で進めています。完成時にこのページが自動的に更新されるので、定期的にチェックしてみてください。

なぜ Windows でも PowerShell?

ブラウザでダウンロードすると Windows が Mark of the Web (MOTW) 属性を付与し、SmartScreen が「Windows によって PC が保護されました」警告を出します。Invoke-WebRequest で取得すると MOTW が付かないため、警告自体が出ません (Mac の curl と同じ哲学)。

正式な Authenticode 署名 (年 $300-600) を取得すれば PowerShell なしでも警告は出ませんが、テスター段階では費用を抑えています。
